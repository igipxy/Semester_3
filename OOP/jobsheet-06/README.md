# Jobsheet 06 - Inheritance

This submission contains the corrected, runnable implementation of all six experiments and the ticket exercise from Jobsheet 06. The Java sources use separate packages so repeated class names such as `ClassA` do not conflict.

## Submission index

- `src/.../experiment1`: fixing a missing `extends` relationship
- `src/.../experiment2`: inheritance and private-field access
- `src/.../experiment3`: `super` and `this`
- `src/.../experiment4`: multilevel constructor chaining
- `src/.../experiment5`: hierarchical employee inheritance
- `src/.../experiment6`: multilevel employee inheritance
- `src/.../exercise`: train, domestic-flight, and international-flight tickets
- `StudyGuide.md`: plain-language explanation of the concepts
- `docs/ANSWERS.md`: answers to every worksheet question
- `docs/EXERCISE.md`: ticket hierarchy, formulas, and implementation evidence
- `docs/output`: verified output text and PNG evidence

## Compile and run everything

Open PowerShell in `OOP/jobsheet-06`, then run:

```powershell
.\verify.ps1
```

The script compiles every Java file and runs Experiments 1-6 plus `TestTiket`.
